# 「같은 대사, 한중일 사극」 쇼츠 제작

같은 대사 하나를 조선·중국·일본 사극 톤으로 연기한 3컷을 비교하고, 반대편 인물이 나와 코믹하게 뒤집는 반전 컷으로 끝나는 쇼츠 시리즈. EP.01 "아니 되옵니다"(2026-10-29)를 실제로 만든 과정이 기준이다. 결과물 예시와 원본 파일은 https://github.com/scene1one1-one/History-Actor 의 `series-same-line/ep01/`.

LTX-2.5 프롬프트 형식과 RunningHub 실행 세부는 `ltx25-video` 스킬을 따른다.

## 사용자와 소통

- 한국어로 답한다. 프롬프트 본문은 영어, 따옴표 안 대사만 원어(한국어/중국어/일본어).
- 생성은 코인이 든다. "만들어"라고 했으면 승인이다. 회당 약 160~220 RunningHub 코인.
- 영상을 다시 만들지 말라고 하면 레이아웃만 미리보기 이미지로 먼저 보여준다.
- 작업 파일은 History-Actor 저장소, 새 스킬은 my-skills 저장소에 올린다.

## 레이아웃 (사용자 확정 2026-10-29)

- 배경은 검은색. 상단에 큰 제목(대사, 신라문화체 `Shilla_CultureB.ttf` 124px)과 부제(페이퍼로지 `Paperlogy-5Medium.ttf` 48px). 작은 시리즈 라벨은 넣지 않는다.
- 영상 위 원어 대사 자막: `LXGWWenKaiKR-Light.ttf` 48px 흰 글자, 테두리 없이 아주 옅게 번진 검은 그림자만(영화 자막 스타일, `glowsub`).
- 나라 배지("1  조선 · 한국"): 페이퍼로지 5 Medium 46px (디자인은 추후 개선 예정).
- 영상 밖 한글 대사: 신라문화체 58px, 테두리·그림자 없음. Clip Wipe로 등장(`scripts/wordfx.py` `linewipe`: HyperFrames `caption-clip-wipe` 이식, 말하는 단어마다 왼쪽→오른쪽 0.3초 와이프, 배경 블록 강조 없음. 단어 타이밍은 `SWEEP` 표에 실제 발화 구간에 맞춰 적는다).
- 인트로 문구: 시리즈 고정 틀 "[주제] / 한중일은 어떻게 다를까?" (위쪽 부제를 강조하는 시작 문장). EP.01은 "목숨 걸고 말리는 신하 / 한중일은 어떻게 다를까?", 나레이션도 같은 문장. Clip Wipe(`wordfx.py` `clipwipe`: `caption-clip-wipe` 이식, 단어별 왼쪽→오른쪽 0.3초 와이프, 페이퍼로지 5 Medium). 첫 줄 핵심어("목숨 걸고")는 노란색 #FFD700, "한중일"은 글자별 테마색 한=흰색 중=빨강 일=파랑(뒤 조사는 흰색). 나레이션은 3.9초 안에 끝나도록 atempo로 맞추고, 단어 타이밍은 faster-whisper word_timestamps로 잡는다.
- 반전 컷: 영상 위 자막은 한국어 대사의 로마자 발음(영어 번역 아님, 폭 1000px 넘으면 글자 자동 축소). 영상 아래(y=1190) 3줄 자막: 한글 대사(흰색), 중국어 번역(빨강), 일본어 번역(파랑), LXGW 글꼴. Line Swap(`wordfx.py` `kingswap`: HyperFrames `line-swap` 이식, 대사가 바뀔 때마다 이전 줄은 위로 빠지고 새 줄이 아래에서 위로 올라옴, 마스크 안에서만 보임, 줄 간격 64px로 좁게 묶어 한눈에 보이게 함). 문구와 시작 시각은 `KING_ML` 표에 적는다.
- HyperFrames 효과 이름을 지정받으면 `npx hyperframes add <이름>`으로 컴포넌트 HTML을 받아 타이밍·색·이징을 확인하고 PIL 프레임 시퀀스로 옮긴다(투명 PNG → ffmpeg overlay). 글꼴 파일: History-Actor `series-same-line/ep01/fonts/`.
- 반전 컷은 영상과 인물 자막만. 배지, 질문 문구, 해시태그를 넣지 않는다.
- 영상은 16:9를 가운데에(y=540, 1080×608). 위아래에 테마 컬러 선.
- 테마 컬러: 조선 흰색, 중국 빨강, 일본 파랑. 나라 배지, 해시태그, 하단 1·2·3 표시에 적용.
- 원어 대사 자막은 영화처럼 영상 하단 위에 입히고, 말하는 구간에만 띄운다 (흰 글자 + 검은 외곽선).
- 나라 컷 영상 밖 배치(위→아래): 나라 배지(y=1190) → 톤 해시태그(y=1300) → 한글 대사(Clip Wipe, overlay y=1390) → 하단 1·2·3. 중국어·일본어 [독음] 줄은 넣지 않는다(사용자 v15).
- 그 밖의 글자(배지, 발음, 해시태그, 인트로·아웃트로): Noto Sans/Serif CJK (`apt-get install fonts-noto-cjk`; GitHub raw 글꼴은 이 환경에서 막힘). TTC 인덱스 JP=0, KR=1, SC=2.
- 구현: `scripts/layout.py` (`CUTS`, `KING`, `THEME`를 회차에 맞게 수정).

## 제작 순서

1. **대본**: 대사 1개, 나라별 원어·한국어 번역, 톤 해시태그, 반전 인물과 대사 2줄.
2. **캐릭터 시트**: 같은 출연진을 회차마다 재사용한다(시리즈 고정 얼굴). 새 인물만 `qwen.py`로 시트 생성(16:9, 밝은 회색 배경, 얼굴 클로즈업 + 정면·측면·후면).
3. **시작 이미지**: 시트를 레퍼런스로 `qwen.py prompt.txt out.png "16:9 (Widescreen)" sheet.png`. 얼굴이 크게 나오게 미디엄 클로즈업이나 허리 위 구도.
4. **영상**: `ltx.py start.png prompt.txt out.mp4 5` (반전 컷은 8). 프롬프트에 의상과 "The lighting stays constant."를 매번 적는다.
5. **검수**: 프레임 타일을 보고, faster-whisper(small)로 대사를 받아 적어 언어와 내용이 맞는지 확인한다. 말하는 구간은 `silencedetect`로 잡는다.
6. **반전 컷 편집**: 무음 0.12초 이상 구간을 기준으로 숨 쉬는 틈을 잘라 이어붙인다(점프컷). 가운데 조각만 1.12배 확대하면 컷 튀는 느낌이 산다. 동작(관 벗기 등)이 무음 구간에 있으면 그 동작 시작은 남긴다.
7. **BGM**: `yue.py "스타일" out.mp3` (YuE2 연주곡, 30초, 약 7~12코인). 인트로용, 나라별 3곡, 반전 코믹용.
8. **나레이션**: ElevenLabs TTS (`ELEVENLABS_MODEL`, `language_code: ko`, speed 1.15). 인트로 약 3.8초, 아웃트로 약 2초.
9. **합성**: `assemble.sh` (작업 폴더 안에서 실행). 대사 -15 LUFS, 나라 BGM -29 LUFS, 코믹 BGM -24 LUFS. BGM은 각 곡 3초 지점부터 쓰고 페이드아웃하지 않는다(사용자 확정). 효과음(사용자 제공, 작업 폴더에 둔다): 나라별 컷 시작마다 `sfx_drum.mp3`(일본 북, -6dB), 반전 컷 시작에 `sfx_tsudumi.mp3`(고츠즈미, -3dB), 반전 컷이 끝나고 아웃트로 시작 순간에 `sfx_end.mp3`(드럼, -3dB).

## 함정

- RunningHub는 동시 작업 약 2개. 코드 421 TASK_QUEUE_MAXED면 10초마다 재시도 (`rh.py`에 들어 있음). 결과 다운로드가 끊기면 `/task/openapi/outputs`로 URL을 다시 받는다.
- Qwen이 명나라 오사모의 양쪽 날개를 빼먹는다. "two long flat black wings sticking straight out" 문장과 허리 위 구도를 넣는다.
- 정좌 전신처럼 얼굴이 작은 컷은 합성 때 zoompan으로 천천히 줌인한다(먼저 2560폭으로 키운 뒤).
- ffmpeg에서 `-loop 1` 자막 PNG를 여러 장 겹치면 출력이 끝나지 않는다. 출력에 `-t 길이`를 꼭 준다.
- crop 필터의 w/h에는 시간식 `t`를 쓸 수 없다. 움직이는 확대는 zoompan.
- `pkill -f 패턴`은 같은 패턴이 든 내 셸까지 죽인다. PID로 끈다.
- 소품 동작(찻잔에 금 가기, 부채 부러뜨리기)은 첫 생성에서 잘 안 나온다(EP.02: 찻잔은 그대로, 부채는 펼쳐짐). "knuckles turn white… the cup cracks loudly, jagged crack lines", "the fan never opens… snaps in two"처럼 결과 상태와 하지 말아야 할 동작까지 적고 시드를 바꿔 재생성한다.
- faster-whisper가 PyAV 버전 충돌(`metadata_errors`)로 파일을 못 열면 ffmpeg로 16kHz mono PCM을 뽑아 numpy 배열로 넘긴다(History-Actor `ep02/scripts/stt.py`).
- 중국 왕비/후궁 클리셰("本宫", 금 호갑투, 량바터우)는 청 궁중극 것이다. 이런 회차는 배지를 "청나라 · 중국"으로 쓴다.
- 아이 인물은 "medium close-up"이라 써도 Qwen이 작게(무릎까지) 그린다. "the camera close so his face fills the upper half of the frame"을 넣는다.
- 동작 펀치라인(손가락 사이로 훔쳐보기)이 안 나오고 엎드려 버리면 "He does not bow down."처럼 하지 말 동작을 적고 시드를 바꾼다. 한 번 재생성은 약 13~20코인.
- 새 컨테이너에는 fonts-noto-cjk와 faster-whisper가 없을 수 있다. `apt-get install fonts-noto-cjk`, `pip install faster-whisper` 먼저.
- 나레이션이 구간보다 길면 assemble에서 `atempo`(EP.03 인트로 1.11)로 맞춘다. 문장 중간 쉼(쉼표)이 길면 atempo 대신 쉼 구간을 잘라낸다(EP.04: `aselect='not(between(t,1.75,2.2))'`).
- faster-whisper 단어 타임스탬프는 앞쪽 무음을 첫 단어에 붙여 0초부터 시작하는 것처럼 나온다. 자막 타이밍은 `silencedetect`의 발화 구간으로 잡는다.
- 새 컨테이너에서 `apt-get install fonts-noto-cjk`가 "Unable to locate package"면 `apt-get update`부터.
- ElevenLabs 키는 TTS만 된다(voices_read, speech_to_text 권한 없음). 받아쓰기는 faster-whisper로.

- 같은 인물의 다른 장면은 캐릭터 시트만 참조하면 얼굴이 달라진다. 이미 쓴 컷의 시작 이미지를 두 번째 참조로 넣고 "keep exactly the same face from image 2"라고 쓴다. 이전 영상의 마지막 프레임을 시작 이미지로 쓰면 영상 중 바뀐 얼굴이 그대로 이어지니 쓰지 않는다. 누운 자세에서 벌떡 일어나는 큰 동작도 얼굴이 흐트러지니 반쯤 기댄 자세에서 시작한다(EP.04 부활 컷). 참조할 컷은 사용자 편집본에서 그 인물이 처음 나오는 컷으로 고른다. EP.04 콜드 오픈 왕은 영상 중 얼굴이 통통해져 시트와 달랐고, 편집본 첫 장면(반전 컷 `start_twist.png`)을 참조해야 맞았다.
