# 로컬 작업 폴더 워크플로

사용자가 컴퓨터의 폴더를 Claude 데스크톱 앱에 연결했을 때 쓰는 절차다. 폴더를 연결하면 참조 이미지를 파일로 관리하고, Claude가 저장된 이미지를 직접 보고 고정 문구를 보정하거나 장면 이미지를 검수할 수 있다. 연결된 폴더가 없으면 이 문서는 건너뛰고 기존 방식(채팅/파일 전달)으로 진행한다.

## 목차
1. 폴더 준비
2. 파일명 규칙
3. 시트 검수와 확정
4. 장면 프롬프트에 파일명 쓰기
5. 파트 완료 후 이미지 검수
6. 도구 사용 메모
7. 연재물과 낭독 대본의 파일 규칙

## 1. 폴더 준비

연결된 폴더 안에 작업 폴더를 만들고 아래 구조로 둔다. **폴더 이름은 시리즈명이나 이야기 제목으로 짓는다**(예: `미배송-보관함/`). 이름을 정하기 어려우면 `story-assets/`를 쓴다. 이야기마다 폴더를 따로 두고, 같은 시리즈의 새 회차는 기존 폴더에 이어서 쓴다. 이미 있으면 새로 만들지 않고 이어서 쓴다. 폴더 이름을 정하기 전에 연결된 폴더 안에 이전 작업 폴더가 있는지 `device_list_dir`로 보고, 있으면 같은 이야기인지 사용자에게 확인한다. 폴더에 같은 이름의 파일이 있으면 덮어쓰기 전에 사용자에게 확인한다.

폴더 구조는 두 가지다. **이야기가 한 편이면 A, 연재물(시리즈, 회차가 있는 대본)이면 B**를 쓴다. B의 파일명 규칙은 §7.

A. 단편
```
<작업 폴더>/
  README.md
  bible/story-bible.md
  refs/ref-status.md
  refs/characters/   CHAR-*, CREATURE-*
  refs/props/        PROP-*
  refs/locations/    LOC-*
  parts/part-N_Sxxx-Syyy.md
  output/            S001.png ...
```

B. 연재물 (예: `미배송-보관함/`)
```
<작업 폴더>/
  README.md
  bible/series-bible.md            시리즈 공통 Bible, 연속성 기록, 공통 시트 프롬프트
  bible/ep01-bible.md              1화 전용 Bible, 시각 단서, 파트 계획, 1화 시트 프롬프트
  script/ep01_제목_대본.md          대본 사본
  script/ep01_timeline.md          story_timing.py 결과
  refs/ref-status.md
  refs/characters/   CHAR-*, CREATURE-*
  refs/props/        PROP-*
  refs/locations/    LOC-*
  parts/ep01_part-N_Sxxx-Syyy.md
  output/            ep01_S001.png ...
```

- `README.md`: 폴더 구조, 파일명 규칙, 작업 순서
- `refs/ref-status.md`: 시트별 저장 파일명과 상태(`미생성` → `생성됨(검수 대기)` → `확정`)를 적은 표
- 빈 폴더는 만들어지지 않으므로 각 폴더에 짧은 `_README.txt`를 넣어 폴더가 생기게 한다.

사용자가 폴더를 아직 연결하지 않았다면 "Claude 데스크톱 앱에서 메시지 입력창 옆 + 메뉴의 Add folder로 폴더를 추가해 주세요"라고 안내한다.

## 2. 파일명 규칙

- 참조 이미지는 Bible의 ID를 파일명으로 쓴다: `CHAR-카엘_COS-A.png`, `PROP-상자.png`, `LOC-지하창고.png`. 상태 변형은 `LOC-갯벌_high-tide.png`처럼 뒤에 붙인다.
- 장면 이미지는 `S001.png`처럼 전체 통번호로 쓴다.
- 재생성은 덮어쓰지 않고 `_v2`, `_v3`를 붙인다. 사용자가 고른 최종본이 어느 것인지는 `ref-status.md`나 검수 결과에 기록한다.
- ID와 파일명이 1:1이어야 장면 프롬프트의 "첨부할 참조 이미지"에 파일명을 그대로 쓸 수 있다.

## 3. 시트 검수와 확정

사용자가 시트 이미지를 저장하고 검수를 요청하면 다음 순서로 진행한다.

1. `device_list_dir`로 `refs/`를 확인하고, `device_stage_files`로 해당 이미지를 가져와 Read로 본다. 한 번에 이미지 여러 장을 보면 토큰이 많이 들므로 한 대화 턴에 8장 안팎으로 나눈다.
2. 이미지에 실제로 그려진 특징(머리 길이와 색, 눈 색, 옷 색과 소재, 소품의 형태, 방의 구조)을 고정 문구와 하나씩 비교한다.
3. 어긋난 항목은 두 가지 중 하나로 처리한다.
   - 그림이 마음에 들면 고정 문구를 **그림에 맞춰 고친다.** 이후 장면 프롬프트가 이미지와 같은 묘사를 쓰게 되어 참조 이미지와 문구가 서로 충돌하지 않는다.
   - 그림이 의도와 다르면 시트를 **다시 생성하도록 안내**하고, 어떤 문구를 보강하면 좋은지 알려 준다.
4. 확정한 시트는 `ref-status.md`의 상태를 `확정`으로 바꾸고, Bible의 해당 항목에 `확정 이미지: 파일명`을 적는다. 고정 문구를 고쳤다면 Bible을 갱신하고, 이미 만들어 둔 파트 파일 중 영향받는 장면 프롬프트도 함께 고쳐서 어떤 장면이 바뀌었는지 알린다.
5. 한 번 확정한 뒤에는 고정 문구를 바꾸지 않는다. 바꿔야 하면 사용자에게 먼저 알리고 승인받는다.

## 4. 장면 프롬프트에 파일명 쓰기

폴더 워크플로에서는 장면의 "첨부할 참조 이미지"를 시트 라벨(A-1) 대신 **파일명**으로 쓴다. 예:

```
- 첨부할 참조 이미지: refs/locations/LOC-지하창고.png, refs/characters/CHAR-카엘_COS-A.png
```

참조 이미지를 쓰는 장면의 프롬프트 시작에는 이 문장을 붙이라고 안내한다: "첨부한 이미지의 인물·소품·배경 디자인을 그대로 유지하고, 아래 장면을 그려줘."

## 5. 파트 완료 후 이미지 검수

사용자가 파트의 장면 이미지를 `output/`에 저장하고 검수를 요청하면 진행한다.

1. `output/`에서 해당 파트의 장면 번호 범위에 해당하는 이미지를 확인한다. 파일이 빠진 번호는 따로 알려 준다.
2. 이미지를 Read로 보고 각 장면을 다음 기준으로 점검한다: 인물 얼굴과 체형, 의상(COS와 STATE), 소품의 형태, 배경 구조, 화풍과 색감, 그림 속 글자 유무.
3. 결과를 장면별로 `통과 / 재생성 권장 / 재생성 필요`로 표시한 표로 준다. 재생성 대상에는 무엇이 어긋났는지 한 줄과, 프롬프트에 보강할 문구를 같이 적는다.
4. 재생성용 수정 프롬프트는 원래 프롬프트에서 어긋난 부분만 고친 버전을 준다. 고정 문구 자체는 그대로 둔다.
5. 검수에 쓴 이미지가 많을 때는 8~10장씩 나눠 보고, 한 번에 몰아서 판단하지 않는다.

주의: 검수 기준은 시트 이미지와 Bible이다. 장면 이미지가 시트와 다르면 장면 쪽을 고친다. 장면 이미지가 더 마음에 든다고 사용자가 말하면 그때만 시트와 Bible을 거기에 맞춰 고친다.

## 6. 도구 사용 메모

- 연결된 폴더 경로는 `get_device_info`로 확인한다. 폴더가 비어 있는지는 `device_list_dir`로 본다.
- 폴더에 파일을 쓸 때는 먼저 컨테이너의 `/mnt/user-data/outputs/` 아래에 파일을 만들고 `device_commit_files`의 `stagedPath`로 보낸다. 이미 `SendUserFile`로 보낸 파일은 `fileUuid`로 보낼 수 있다.
- 폴더의 이미지를 읽을 때는 `device_stage_files`로 가져온 뒤 Read로 본다. 가져온 파일은 그 시점의 복사본이므로, 사용자가 이미지를 바꿨을 수 있으면 `device_list_dir`로 수정 시각을 확인하고 다시 가져온다.
- Claude는 이미지를 생성하지 못한다. 시트와 장면 이미지의 생성, 저장, 첨부는 사용자가 ChatGPT나 Gemini에서 직접 한다. 이 폴더는 정리와 검수를 위한 것이다.

## 7. 연재물과 낭독 대본의 파일 규칙

연재물은 작업 폴더 하나가 시리즈 하나를 뜻한다. §1의 B 구조를 쓰고, **파일명에 회차 접두사(`ep01_`)를 붙여** 회차를 구분한다. 2화부터는 폴더를 새로 만들지 않고 같은 폴더에 `ep02_` 파일을 추가한다.

```
<작업 폴더>/
  bible/series-bible.md            시리즈 공통 Bible과 연속성 기록
  bible/ep01-bible.md              1화 전용 Bible
  script/ep01_제목_대본.md          대본 사본 (낭독용)
  script/ep01_timeline.md           story_timing.py 결과
  parts/ep01_part-1_S001-S019.md    파트별 장면 프롬프트
  refs/                             참조 이미지 (시리즈 안에서 ID가 겹치지 않게)
  output/ep01_S001.png              장면 이미지
```

- 장면 이미지는 `ep01_S001.png`처럼 회차 접두사와 장면 번호로 쓴다. 재생성은 `ep01_S007_v2.png`.
- 참조 이미지의 파일명은 Bible의 ID 그대로다(`CHAR-카엘_COS-A.png`). 시리즈 Bible에 있는 항목의 시트는 회차가 바뀌어도 그대로 재사용한다.
- 단편이거나 시리즈 구분이 필요 없으면 접두사 없이 `story-bible.md`, `part-1_S001-S016.md`, `S001.png`를 쓴다. 이 규칙으로 만든 폴더에 나중에 2화를 이어 쓰게 되면, `story-bible.md`의 공통 항목을 `series-bible.md`로 옮기고 1화 전용 항목은 `ep01-bible.md`로 나눈 뒤 기존 파일은 지우지 않고 그대로 둔다. 사용자에게 이 분리를 알리고 진행한다.
- 같은 폴더에 이전 버전의 Bible이나 파트 파일이 남아 있고 대본이 그 뒤에 수정되었다면, 낡은 파일을 덮어쓰지 말고 새 이름으로 만든 뒤 어느 파일이 최신인지 알린다.
- 대본이 수정되어 Bible의 설정과 어긋나는 부분이 생기면 어긋난 항목을 목록으로 먼저 보여 주고, 사용자가 승인한 항목만 고친다.
