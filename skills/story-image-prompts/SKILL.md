# Story → Image Prompts

이야기 텍스트를 받아서, 이미지 생성 모델(ChatGPT / Gemini 등 대화형 이미지 모델)에 바로 붙여넣을 수 있는 **일관성 유지형 프롬프트 세트**를 만든다. 낭독 대본이면 각 이미지가 대본의 어느 시각에 들어가는지까지 맞춘다.

## 왜 이 스킬이 필요한가 (핵심 원리)

이미지 모델은 장면마다 "처음 보는 것처럼" 그린다. 이름("카엘")은 아무 의미가 없고, 앞 장면의 얼굴·옷·방 구조를 기억하지 못한다. 그래서 장면마다 인물이 달라지는 문제가 생긴다.

해결책은 단순하다. **한 번 확정한 외형 묘사를 글자 그대로 모든 프롬프트에 반복 삽입**하고(고정 문구), 가능하면 **첫 생성 이미지를 참조 이미지로 첨부**한다. 연재물에서는 이 고정 문구와 참조 이미지가 회차를 넘어서도 유지되어야 한다. 이 스킬의 모든 절차는 이 두 가지를 위해 존재한다.

## 사용자 설정 (기본값)

- 대상 도구: ChatGPT 이미지 / Gemini 이미지 (자연어 문장형 프롬프트)
- 출력 언어: 영어 + 한국어 (각 프롬프트마다 두 버전)
- 일관성 방식: 캐릭터 시트 + 고정 문구 (Anchor Block)
- 화면비: 영상용이면 16:9

사용자가 다른 도구(Midjourney, Stable Diffusion 등)나 언어를 요청하면 그에 맞게 바꾼다. 이 경우 `references/prompt-templates.md`의 "도구별 변형"을 참고한다.

## 시작할 때 파악할 것 (한 번만)

입력을 받으면 아래 네 가지를 먼저 판단한다. 대본이나 대화에서 알 수 있는 것은 묻지 말고 가정을 밝히며 진행한다. 알 수 없는 것만 한 번에 묶어서 묻는다.

1. **낭독 대본인가.** 파일 상단에 "예상 낭독 시간"이 있거나 `· · ·` 장면 전환이 있으면 낭독 대본이다(`dnd-sleep-story` 스킬의 출력 형식). 이 경우 "작업 흐름 0단계"와 `references/narration-sync.md`를 따른다.
2. **연재물인가.** 시리즈명과 회차가 있거나 시리즈 바이블 파일이 있으면 연재물이다. "연재물 관리"를 따른다.
3. **총 장면 수.** 사용자가 정했으면 그대로, 정하지 않았으면 낭독 시간을 컷 길이(기본 15초)로 나눈 값을 제안한다.
4. **로컬 폴더가 연결되어 있는가.** `get_device_info`의 `connectedFolders`로 확인한다. 연결되어 있으면 "로컬 폴더가 연결되어 있을 때"를 따른다.

## 작업 흐름 (한 회차 기준)

아래 0~5단계는 한 번의 생성 절차를 가리킨다. 뒤의 "대량 작업"에서 말하는 "파트"는 한 회차를 쪼갠 구간이라 둘을 혼동하지 않는다.

### 0단계. 낭독 타임라인 만들기 (낭독 대본일 때만)

긴 글의 글자 수는 눈으로 세면 틀리므로 스크립트로 계산한다.

```
python scripts/story_timing.py <대본.md> --parts 5 --images <N> --out <작업폴더>/epNN_timeline.md
```

스크립트는 헤더와 본문 뒤의 에피소드 기록을 제외하고, `· · ·` 단위의 구간별 글자 수, 낭독 시각, 장면 수, 5개 파트 분할안, 문단·문장 ID별 시작 시각을 낸다. 헤더에 적힌 글자 수와 일치하는지 먼저 확인하고, 어긋나면 사용자에게 알린다. 세부 규칙은 `references/narration-sync.md`에 있다.

### 1단계. 이야기 읽고 분석하기

이야기 전체(또는 이번에 받은 부분)를 읽고 다음을 뽑는다.

- 등장인물 (주연/조연/단역 중 **그림에 나올 인물만**)
- 의상 (장면·시간 경과에 따라 바뀌는지)
- 소품 (반복 등장하거나 이야기에 중요한 것)
- 장소 (반복 등장하는 곳은 구조까지)
- 시대·분위기·계절·시간대
- 장면 전환 지점 (대본이면 `· · ·`가 작가가 정한 경계다)
- **시각 단서 목록**: 이야기의 전개가 눈에 보이는 디테일에 달린 것들. 예를 들어 "먼지 위에 남은 손바닥만 한 네모꼴 자국", "벽 쪽으로 내려앉은 판자 모서리", "멈칫하는 불빛의 박자"처럼 독자가 알아채야 이야기가 풀리는 것이다. 단서마다 반드시 그 디테일이 보이는 컷을 하나 배정한다. 단서 컷이 빠지면 이야기의 인과가 이미지에서 끊어진다.

이야기에 외형 정보가 없는 부분(머리색, 나이, 체형, 방 구조 등)은 **문맥에서 가장 자연스럽게 추정해 채운다.** 단, 추정한 항목은 Bible에 `(추정)` 표시를 붙여 사용자가 쉽게 수정하도록 한다. 한 번 확정된 뒤에는 절대 바꾸지 않는다. 확정 전에 바꾸는 게 훨씬 싸기 때문이다. 시리즈 바이블에 외형이 적혀 있으면 그것이 정본이다.

### 2단계. Bible 만들기 (가장 중요)

`references/consistency-guide.md`를 읽고 따른다. Bible은 다음으로 구성된다.

1. **STYLE LOCK** — 전체 그림체·색감·조명·화면비. 모든 프롬프트 끝에 동일하게 붙는다.
2. **CHARACTER ANCHORS** — 인물별 고정 문구 (`CHAR-카엘` 등 ID 부여)
3. **COSTUME VARIANTS** — 의상이 바뀌는 인물은 `CHAR-카엘/COS-A`, `COS-B`처럼 의상별로 분리
4. **PROP ANCHORS** — 중요 소품별 고정 문구
5. **LOCATION ANCHORS** — 장소별 고정 문구 (구조·색·시간대 변형 포함)

각 Anchor는 영어 고정 문구(실제 프롬프트에 삽입) + 한국어 설명(사용자 확인용)으로 쓴다. 이름 대신 외형 묘사를 쓴다. 이미지 모델은 이름을 모르기 때문이다. 연재물이면 시리즈 공통 항목과 회차 전용 항목을 나눠 쓴다("연재물 관리").

### 3단계. 참조 이미지 생성용 시트 프롬프트 만들기

Bible을 만든 직후, 일관성의 뿌리가 되는 **시트 프롬프트**를 같이 제공한다.

- 인물별 캐릭터 시트 (정면/측면/후면 + 표정 + 의상)
- 중요 소품 시트
- 핵심 장소 배경 플레이트 (인물 없는 빈 배경)

사용자가 이 시트를 먼저 생성해 마음에 드는 결과를 얻으면, 이후 장면 생성 때 해당 이미지를 **참조 이미지로 첨부**하라고 안내한다. 템플릿은 `references/prompt-templates.md`. 이미 시리즈 시트가 확정되어 있으면 새로 만들지 않고 재사용한다.

### 4단계. 장면별 프롬프트 만들기

이야기를 장면(샷) 단위로 나누고, 장면마다 아래 형식으로 쓴다. 장면 번호는 회차마다 S001부터 시작한다.

```
### S017 — 한 줄 제목
- 원문: P10.2–P11.1 · 04:48 시작 · 약 14초   (낭독 대본일 때)
- 장면 요약: (한국어 1~2문장)
- 등장: CHAR-xxx/COS-x, PROP-xxx
- 장소: LOC-xxx (시간대/날씨)
- 구도: 샷 종류, 카메라 각도
- 첨부할 참조 이미지: (있다면. 폴더 모드에서는 파일명으로)
- 오버레이 문구(선택): (영상 자막으로 넣을 글귀)

**EN Prompt**
(Anchor 문구를 그대로 삽입한 영어 프롬프트 + STYLE LOCK)

**KO 프롬프트**
(같은 내용의 한국어 버전)
```

장면 프롬프트 작성 규칙:

- 등장 인물의 Anchor를 **한 글자도 바꾸지 말고** 그대로 복사해 넣는다. 요약하거나 동의어로 바꾸면 그 순간 얼굴이 달라진다.
- 장면에서 달라지는 것(표정, 포즈, 행동, 조명, 카메라)만 새로 쓴다.
- 감정은 추상어("슬퍼한다") 대신 보이는 것("눈가가 붉고 입술을 꽉 다문")으로 번역한다.
- 소리, 움직임, 시간 경과, 대사는 정지 이미지로 그대로 옮길 수 없으므로 `references/prompt-templates.md`의 "정지 이미지로 옮기는 법"에 따라 시각적 대응물로 바꾼다.
- 한 이미지에는 하나의 순간만 담는다. 이야기의 서술이 여러 행동을 포함하면 컷을 나눈다.
- 인물이 3명 이상이거나 위치 관계가 중요하면 "왼쪽부터 A, B, C" 식으로 배치를 명시한다.
- 소품에 적힌 글귀(꼬리표, 장부, 편지, 액자)는 이미지 안에서 읽을 수 없는 필기로 그리고, 이야기에 중요한 글귀는 "오버레이 문구"로 따로 적어 영상 편집에서 자막으로 넣게 한다. 이미지 모델은 한글을 틀리게 그린다.
- 이야기에 없는 중요한 설정을 새로 지어내지 않는다. 필요하면 Bible에 `(추정)`으로 올린다.

### 5단계. 일관성 체크 후 전달

전달 전에 스스로 점검한다.

- 모든 장면 프롬프트의 Anchor 문구가 Bible과 글자 그대로 일치하는가
- STYLE LOCK이 모든 프롬프트에 동일하게 붙어 있는가
- 의상/소품의 상태 변화(찢어진 옷, 다친 팔, 줄어든 장부 줄)가 이야기 순서대로 반영되어 있는가
- 시각 단서 목록의 모든 항목에 컷이 있는가
- 영어/한국어 버전의 내용이 서로 같은가
- 추정 항목이 표시되어 있는가
- 낭독 대본이면 장면 번호가 연속이고 시작 시각이 순서대로 늘어나며 장면 수 합계가 계획과 맞는가

## 대량 작업: 5개 파트 분할 생성

이미지가 많은 작업(대략 30장 이상이거나 사용자가 "100장"처럼 큰 수를 말한 경우)을 한 번에 다 만들면 응답이 너무 길어져 뒤로 갈수록 Anchor가 흐트러지고 누락이 생긴다. 그래서 **회차를 5개 파트로 나누고, 한 번에 한 파트의 프롬프트만 생성한다.** 파트 수는 기본 5개다.

### 진행 방식

1. **준비 라운드 (첫 응답)**: 장면 프롬프트는 만들지 않고 아래만 낸다.
   - Bible 전체 (작업 흐름 1~3단계: 분석, Bible, 시트 프롬프트)
   - **파트 분할 계획표**: 파트별 구간, 낭독 시각, 핵심 사건, 장면 수, 장면 번호 범위
2. 사용자가 계획과 Bible을 확인·수정하면 **파트 1**을 생성한다.
3. 사용자가 "다음", "2파트" 등으로 요청할 때마다 다음 파트를 생성한다. 한 응답에 두 파트 이상을 몰아서 만들지 않는다.
4. 사용자가 특정 파트를 다시 요청하거나 수정하면 그 파트만 다시 만든다.

### 파트 나누는 기준

- 낭독 대본이면 `story_timing.py`의 파트 분할표를 기본안으로 쓴다. 이야기 흐름에 비춰 조정하되 이유를 한 줄 적는다.
- **파트 경계는 `· · ·` 구간 경계에서만 자른다.** 한 구간은 장소, 조명, 인물이 같은 하나의 장면 단위라서 두 파트로 쪼개면 같은 방이 서로 다른 응답에서 다르게 그려질 위험이 있다.
- 장면 수는 낭독 시간에 비례해 배분한다. 구간별로 조정하고 싶으면 사용자가 요청할 때만 `--weights`를 쓴다.
- 낭독 대본이 아니면 이야기의 큰 전환점(발단, 전개, 위기, 절정, 결말)으로 자르고, 인물·장소·의상이 크게 바뀌는 지점을 경계로 삼는다.
- 장면 번호는 **회차 안에서 통번호**로 매긴다(S001~S100). 파트가 바뀌어도 번호가 이어져야 사용자가 생성한 이미지 파일을 순서대로 관리할 수 있다.
- 계획표 형식:

```
| 파트 | 구간 | 낭독 시각 | 핵심 사건 | 장면 수 | 번호 |
|---|---|---|---|---|---|
| 1 | 1 | 00:00–04:48 | ... | 19 | S001–S019 |
```

### 파트 생성 시 규칙

- 그 파트에 해당하는 **이야기 구간만** 다시 읽는다. 앞 파트의 장면 프롬프트를 다시 쓰지 않는다.
- 파트 시작에 **Bible 추가분**을 먼저 쓴다. 새로 등장하는 인물·소품·장소·의상이 있으면 여기서 Anchor를 확정한다. 추가분이 없으면 "추가 없음"이라고 쓴다. 기존 Anchor는 절대 고치지 않는다. 고쳐야 한다면 사용자에게 먼저 알리고 승인받은 뒤 반영한다.
- 이 파트에서 처음 나오는 인물·소품·장소의 시트 프롬프트도 이때 같이 준다.
- 장면 프롬프트는 작업 흐름 4단계의 형식을 그대로 따른다. 이전 파트와 이어지는 인물이 있으면 이전 파트의 인수인계 메모를 기준으로 의상·상태를 이어간다.
- 파트를 마치기 전에 작업 흐름 5단계의 일관성 체크를 한다.

### 파트 끝의 인수인계 메모 (Handoff)

파트가 바뀌면 앞 파트의 맥락이 끊기기 쉬우므로, 파트를 끝낼 때 다음 파트가 이어받을 상태를 반드시 적는다. 사용자가 새 대화창에서 이어가도 Bible과 이 메모만 있으면 이어갈 수 있게 한다.

```
## HANDOFF — 파트 N 종료 시점 (마지막 장면 S0xx, 낭독 mm:ss)
- 이야기 위치: (마지막 사건 한 줄)
- 장소/시간대/날씨: LOC-xxx / night / rain
- 인물별 현재 상태: CHAR-xxx — COS-B, STATE-mud / CHAR-yyy — COS-A, 정상
- 소품 현재 상태와 소지자: PROP-xxx — 손상 없음, CHAR-xxx가 보유
- 새로 확정된 Anchor: (이 파트에서 Bible에 추가한 항목 ID 목록)
- 다음 파트 시작 예고: (다음 파트 첫 사건 한 줄)
```

### 파트 응답 구성

1. 파트 헤더 (파트 번호, 장면 범위 S0xx–S0yy, 구간, 낭독 시각 범위)
2. Bible 추가분 + 신규 시트 프롬프트 (없으면 "추가 없음")
3. 장면별 프롬프트 (EN + KO)
4. 일관성 점검 결과 (짧게)
5. HANDOFF 메모
6. 한 줄 안내: "다음 파트를 만들려면 '파트 N+1'이라고 말씀해 주세요."

분량이 길어 채팅에 다 담기 어려우면 파트별 마크다운 파일로 저장해 전달하고, 채팅에는 요약과 파일을 준다.

## 연재물 관리

연재물은 같은 주인공과 같은 장소가 회차를 넘어 반복된다. 그림이 회차마다 달라지면 시리즈의 얼굴이 사라지므로, Bible을 두 층으로 나눈다.

- **시리즈 Bible** (`series-bible.md`): STYLE LOCK, 주인공과 반복 인물의 Anchor와 의상, 매 회 반복되는 장소(예를 들어 길드 창고, 접수대)와 소품(방패, 수첩), 장기 떡밥의 시각 모티프(방패의 움푹 팬 자국처럼 회차를 넘어 이어지는 단서), 시리즈 바이블의 금지·주의를 시각 규칙으로 옮긴 것
- **회차 Bible** (`epNN-bible.md`): 이번 회에만 나오는 인물, 소품, 장소, 의상
- 회차 Bible의 항목이 다시 나오면 **시리즈 Bible로 승격**한다. ID는 그대로 둔다.
- 회차가 끝나면 시리즈 Bible 맨 아래의 **연속성 기록**에 회차 끝 상태를 추가한다. 예를 들어 "수첩 첫 장에 한 줄 기록됨, 둘째 장 첫 줄에 선이 그어짐"처럼 다음 화 그림에 영향을 주는 상태다.
- 새 회차를 시작할 때는 시리즈 Bible과 연속성 기록을 먼저 읽고, 시리즈 시트 이미지는 재사용한다. 이미 확정한 주인공 Anchor와 STYLE LOCK은 새 회차에서도 바꾸지 않는다.
- 입력에 시리즈 바이블 파일(`series_bible_*.md`)이나 대본 끝의 "에피소드 기록"이 있으면 읽고, 주인공 외형·늘 지니는 물건·반복 요소·금지/주의를 시각 Bible에 반영한다.
- 파일명과 폴더 규칙은 `references/asset-folder.md`.

## 로컬 폴더가 연결되어 있을 때

사용자가 Claude 데스크톱 앱에 폴더를 연결했다면 그 안에 작업 폴더를 만들어(폴더 이름은 시리즈명이나 이야기 제목, 예: `미배송-보관함/`. 정해진 이름이 없으면 `story-assets/`) Bible, 파트 파일, 참조 이미지, 장면 이미지를 한곳에서 관리한다. 이렇게 하면 두 가지가 가능해진다.

- 시트 이미지를 Claude가 직접 보고 **고정 문구를 실제로 그려진 모습에 맞춰 보정한 뒤 확정**한다. 문구와 참조 이미지가 어긋나면 모델이 둘 사이에서 흔들리기 때문이다.
- 파트가 끝난 뒤 장면 이미지를 보고 **얼굴, 의상, 배경이 시트에서 벗어난 장면을 골라 재생성 목록**을 만든다.

폴더 구조, 파일명 규칙, 시트 검수와 장면 검수 절차, 도구 사용법은 `references/asset-folder.md`에 있다. 폴더 작업을 시작하기 전에 읽는다. 폴더가 연결되어 있지 않으면 이 방식을 강요하지 않고 기존 방식으로 진행하되, 폴더 연결의 장점을 한 줄로 안내한다. 이미지 생성과 저장, 첨부는 항상 사용자가 직접 하며 Claude는 이미지를 만들지 못한다. 폴더 모드에서는 장면의 "첨부할 참조 이미지"를 시트 라벨 대신 **파일명**으로 쓰고, 시트 프롬프트를 줄 때 저장할 파일명을 함께 알려 준다.

## 이어지는 이야기 / 수정 요청 처리

- 이야기가 이어서 들어오면 기존 Bible을 **갱신**한다. 기존 Anchor는 유지하고, 새 인물·장소·의상만 추가한다.
- 사용자가 "머리를 짧게 바꿔줘" 같은 수정을 요청하면 Bible의 해당 Anchor만 고치고, 영향받는 모든 장면 프롬프트에 반영한다. 어떤 장면이 바뀌었는지 알려준다.
- 사용자가 생성된 이미지를 보여주며 "얼굴이 달라졌어"라고 하면, 이미지에서 실제 보이는 특징을 기준으로 Anchor를 보강하고 해당 인물의 시트를 다시 제안한다.
- 대본이 수정되어 다시 들어오면 `story_timing.py`를 다시 돌려 시각이 어떻게 달라졌는지 확인하고, 바뀐 구간의 장면만 고친다. 예전 Bible과 다른 설정이 대본에 새로 생겼는지(예를 들어 장소에 창이 추가됨) 먼저 비교해서 알린다.

## 안전·권리 관련

- 실존 인물이나 저작권이 있는 캐릭터(만화·애니·영화 등)가 이야기에 나오면 그 인물을 그대로 그리는 프롬프트는 만들지 않는다. 대신 이야기 속 역할에 맞는 **독창적인 외형의 인물**로 바꾸고 그 사실을 알린다.
- 미성년자 인물은 연령에 맞는 일상적·비선정적 묘사만 쓴다. 신체 노출이나 선정적 묘사는 쓰지 않는다.
- 잔혹/폭력 장면은 이야기에 필요하면 분위기와 결과 중심으로 암시적으로 표현하고, 신체 훼손 같은 노골적 묘사는 피한다.
